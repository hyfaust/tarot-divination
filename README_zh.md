## 功能特性

- **78 张塔罗牌** — 完整的韦特塔罗牌组，中英双语牌义（正位和逆位）
- **6 种牌阵** — 单牌占卜、三牌阵、凯尔特十字、马蹄形、关系牌阵、决策牌阵
- **语言切换** — 全站中英文无缝切换（含牌义数据）
- **每日一牌** — 每天抽取一张牌，使用 localStorage 持久化
- **牌义查询** — 搜索和筛选全部 78 张牌的详细含义
- **神秘主题** — 暗色背景 + 金色点缀 + 星空动画 + 翻牌特效
- **响应式设计** — 支持桌面和移动端
- **零依赖** — 纯 HTML + CSS + JavaScript，无需构建工具

## 快速开始

1. 在任意现代浏览器中打开 `index.html`。

2. 或使用本地服务器（推荐获得最佳体验）：

   ```bash
   # Python
   python -m http.server 8080

   # Node.js
   npx serve .
   ```

3. 访问 `http://localhost:8080`。
